# Assistant (小助)

An offline life-assistant app that runs entirely on your iPhone. It wires together high-frequency scenarios — to-dos, expense tracking, parcel pickup, an ID document vault, and voice chat — into a "keep-your-phone-in-your-pocket" loop. All data stays on the device, with on-device speech recognition and optional local LLM inference, plus Live Activities, home/lock-screen interactive widgets, and Apple Watch Smart Stack integration.

- Platform: iOS 18.0+, portrait-only (iPhone)
- UI languages: Simplified Chinese / English (`zh-Hans` is the development language)
- Signing: free Personal Team certificate, valid for 7 days, with scripts for automatic renewal

## Core Features

| Module | Description |
| --- | --- |
| To-do Center | Categorized to-dos, overdue triage, recurrence rules, completion history, notification scheduling and snooze |
| Voice Assistant | Long-press the floating voice ball to start a conversation directly; offline ASR transcription + a unified intent processor routing to each module |
| Omnibox Single-Entry Capture | Text / voice / screenshot multimodal input, automatically dispatched to create to-dos, expenses, or item records |
| One-Sentence Expense Tracking | Colloquial amount parsing (homophone normalization, Chinese numerals), budget with a dynamic "spend-with-peace-of-mind today" allowance, recurring expenses auto-posted |
| Parcel & Departure Scenarios | Geofence arrival reminders; pickup codes surfaced on the Dynamic Island / lock screen / Watch — tap "Picked up" on your wrist to dismiss |
| Life Archive | ID document vault (Face ID-protected), encrypted password vault, item storage with daily holding cost, vehicle / pet / child / anniversary / life-event management |
| Habits & Medication | Periodic habit check-ins, medication schedule evaluation and reminders |
| Contextual Intelligence | Autonomous learning of frequent places, daily pain-point audit (low battery, expiring documents, auto-renewal prevention), periodic review reports |
| Model Management | Download and manage local GGUF models; can also connect to Ollama on the LAN |
| System Integration | App Shortcuts, Action Button, Back Tap, interactive home-screen widgets, Live Activities, completing to-dos directly from widgets |
| Data Safety | Full backup/restore (PIN-encrypted export/import), app lock passcode, senior mode, customizable tab bar and app background |

## Tech Stack

- **SwiftUI + SwiftData**: all UI and persistence; SwiftData uses a versioned migration plan, and on migration failure the original store is preserved with a recovery/export entry point (see `Assistant/Services/Persistence.swift`)
- **ActivityKit / WidgetKit / AppIntents**: Dynamic Island Live Activities, interactive widgets, and system shortcuts; the main app and the extension share snapshots and a command queue via an App Group (`group.com.yifanwang.assistant01`)
- **Speech / AVFoundation**: offline speech recognition and audio recording/transcription
- **LlamaSwift** (external SPM package): on-device LLM inference runtime
- **AssistantCore** (local SPM package): pure logic such as rule parsing and parcel matching, independently testable
- **XcodeProj**: the project file is generated by `xcodegen` from `project.yml`; the `.xcodeproj` is never maintained by hand

## Build & Run

Prerequisites: macOS + Xcode 16+, `brew install xcodegen`.

```bash
# 1. Generate the Xcode project (project.yml is the single source of truth; just regenerate)
xcodegen generate

# 2. Open Assistant.xcodeproj in Xcode, select the Assistant scheme, and run
```

### Installing on a Device & 7-Day Renewal (Free Account)

```bash
cp scripts/config.example scripts/config.local   # fill in DEVELOPMENT_TEAM, BUNDLE_ID, DEVICE_ID
scripts/reinstall.sh                              # build Release and install to the iPhone
scripts/install_auto_renew_agent.sh               # install the auto-renew agent (reinstalls before the 7-day expiry)
```

## Testing

Pure-logic tests live in `Packages/AssistantCore/Tests/`:

```bash
cd Packages/AssistantCore && swift test
```

## Privacy Notes

- To-dos, expenses, ID documents, passwords, etc. are stored only on the device; backup files are PIN-encrypted exports.
- By default, on-device speech recognition and rule processing work without network access; conversation context is sent to an endpoint only if you manually enable remote inference via Ollama on the LAN.
- Permissions (notifications, location, microphone, photo library, Face ID, etc.) are requested on first use of the relevant feature and can be revoked anytime in System Settings.
